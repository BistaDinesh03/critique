## How to Get Started

1. Pick an issue from this list.
2. Comment on the issue to let maintainers know you're working on it.
3. Read [first-contribution.md](first-contribution.md) for a step-by-step guide.
4. Fork the repository and create a branch.
5. Make your changes and add tests.
6. Run the test suite: `GITHUB_CLIENT_ID=ci-test-client-id python -m pytest tests/ -q`
7. Open a pull request.
