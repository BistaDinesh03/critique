Reading this report

  • Snapshot, not live data. These values were supplied to this report and are not read from the application database. The owner dashboard at /api/analytics/dashboard continues to compute live totals from recorded events and is untouched by this file. Nothing here updates on its own.
  • Reporting period unspecified. No date range accompanied the supplied figures, so the report shows no trend, growth, or comparison line. Any such chart would be invented, so none is shown.
  • Three kinds of figures. event values count recorded event rows; user value counts distinct visitor cookies; rate values are derived by division. Unique visitors (293) is the only user count here — every other number is an event count or a rate.
  • Submission errors — what the data can and cannot say. The client fires feedback_submit_error on exactly four paths: HTTP 409 (a response already exists), HTTP 403 (expired session / CSRF), any other non-success status, and a thrown network or parse exception. An HTTP 401 sign-in gate deliberately fires neither an error nor a success event. Because the analytics_events table stores only event_name, visitor_id, user_id, project_id and created_at, there is no status code or reason dimension — so the 30 errors cannot be attributed to a specific cause from this snapshot, and no cause is claimed here. Note also that the 401 gate counted as an error before commit cb57059 (2026-09-30); without a reporting period it is unknown whether the supplied window spans that change.
  • Attempt arithmetic. 61 attempts − 18 submissions − 30 errors = 13 attempts with no recorded outcome (21.3%). That residual is consistent with the sign-in-gate path in current code, which records the attempt but no outcome event — but with the reporting period unknown this is an arithmetic observation, not a verified cause.
  • Zeros are data. share_copy_link is 0. It is rendered as 0 rather than omitted, because "nobody used this action" and "this action was not measured" mean different things, and this snapshot supplies the metric explicitly.
