# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, email the maintainers directly. We will respond as quickly as possible.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅ |

## Security Considerations

Critique handles user data and authentication. Please:

- Never commit secrets or credentials
- Use environment variables for all sensitive values
- Follow secure coding practices
- Test for common vulnerabilities (XSS, CSRF, injection)

## Acknowledgments

We appreciate responsible disclosure and will credit researchers who report valid vulnerabilities.
